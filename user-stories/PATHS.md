# Managed HTTP paths

Paths are relative to the configured prefix. Limited routes resolve the current credential. Active routes also require activation by default. The session CSRF endpoint is included for any non-empty session capability selection unless excluded. See the [route definitions](../src/http/routes.ts), [request execution](../src/http/managed_execution.ts) and [registration tests](../tests/managed_http_route_registration.spec.ts).
